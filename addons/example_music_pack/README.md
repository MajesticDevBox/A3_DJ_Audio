# Event DJ example music pack

This optional PBO contains two original synthesized test signals for V0.2 native
playback, pause/resume, seek, cue, deck-switch, and JIP testing. It contains no
commercial recording. Remove `edj_example_music_pack.pbo` from a production mod
set when development signals are not wanted.

The OGG files are generated from FFmpeg sine sources at 48 kHz stereo and 96 kbps.
