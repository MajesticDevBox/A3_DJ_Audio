# Contributing

Keep changes bounded to V0.1 until its acceptance checklist passes. Use EDJ names,
small functions and explicit locality. Run hemtt check/build; validate networking
with a dedicated server, two clients and JIP. Record actual RPT evidence. Do not
claim compiler checks prove audible sound. Follow existing remote guards and
provider boundaries. No copied dependency code or unlicensed music/assets.
Licensing is pending. Agree a license before public redistribution. Future work
can use feature branches; no automatic commits/pushes or branch changes are made.
