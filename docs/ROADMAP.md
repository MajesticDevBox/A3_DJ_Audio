# Roadmap

V0.1 and V0.2 are runtime accepted. This task stops after V0.2 validation; V0.3
work has not begun.

| Version | Scope / status |
| --- | --- |
| 0.1 | Accepted: foundation, one operator/PA/source, AE3 workstation, streaming, JIP |
| 0.2 | Accepted: Deck A/B, library, queue, metadata, local cue, capability-aware finite controls, CUT switching |
| 0.3 | Multiple PA zones, presets, range, links and per-zone gain |
| 0.4 | Client-local lights, moving head pan/tilt, presets, blackout and intensity |
| 0.5 | Line arrays, subs, monitors, truss, platforms, barriers, cases, racks and DJ booth |
| 0.6 | Modular LED panels, event art, metadata and static/video presets |
| 0.7 | AE3 production consumption, failures, recovery and power dashboard |
| 0.8 | External DJ software -> streaming server -> Carpinchos -> stage |

Lighting will synchronize preset/state and epoch, with client-local animation.
LED walls will use replaceable model selections and addon-provided media; no
per-frame network updates or mission music payload. External DJ software should
perform real DSP/mixing. Do not implement waveform analysis, beat matching, EQ,
scratch, crossfading, cloud playlists or web administration during V0.1.
