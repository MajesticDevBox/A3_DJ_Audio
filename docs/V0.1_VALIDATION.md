## Discrepancies found and fixed

- Compatibility PBOs now explicitly require the dependency patches whose APIs they call.
- Provider discovery now comes from config, so the audio PBO has no hard reference to an absent optional adapter.
- One commit function now owns revision increments, state mutation, and publication.
- Request payloads are type-checked before scalar parsing and volume clamping.
- Failed audio starts are latched to a play generation instead of retrying after every unrelated snapshot.
- Carpinchos source IDs include the play generation and reject competing local sources.
- UI teardown removes controls and periodic handlers on remount and close.
- Addon remote-execution entries no longer impose a global policy on every mission and dependency.
- Debug inspection is local-only and is absent from the remote whitelist.
- The runtime pass removed an immediate Carpinchos `source:exists` race that destroyed
  a valid source while the dependency was still registering it asynchronously.
- Runtime logging now correlates request owner/type, full state revision context,
  source creation/destruction, gain application, and UI mount/teardown.
- Reproducible smoke, dedicated-server, and role-specific client launch scripts now
  use correctly quoted Arma parameters and fresh test-mission copies.
- The installed AE3 web and native desktops use separate registries. Event DJ now
  uses the public web-extension registry with a per-laptop variable filter and a
  hidden singleton native helper for the preserved window implementation.
- `EDJ: Add Event DJ Workstation` validates exactly one synchronized AE3 laptop on
  the server, ensures AE3 initialization, and publishes `EDJ_isWorkstation` for
  hosted, dedicated, and JIP clients.
