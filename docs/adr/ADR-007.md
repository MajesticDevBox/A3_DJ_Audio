# ADR-007: Config-driven music registry

Status: Accepted for V0.2

Third-party addons register finite tracks in `CfgEventDJTracks` and streams in
`CfgEventDJStreams`. Event DJ validates and normalizes these classes once during
preInit into an ID-keyed cache. Clients submit only IDs; the server resolves source
paths and URLs. Malformed and duplicate addon records are skipped with diagnostics;
mission stream definitions may intentionally replace an ID.
