# ADR-008: Server-authoritative two-deck state

Status: Accepted for V0.2

Deck A, Deck B, queue, active output, and now-playing data remain fields of the
existing stage. `commitStage` is still the only revision and publication boundary.
This preserves authorization and JIP ordering while allowing client-local provider
instances. V0.2 permits one PA output and uses deterministic CUT transitions.
